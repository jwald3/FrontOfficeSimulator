# Security

Front Office is a static site: it has no server, accounts or stored user data, and saves live only in your browser's local storage.

If you find a security problem (in the code, the build, or the GitHub workflows), please report it privately through **Security → Report a vulnerability** on this repository rather than opening a public issue. You'll get a reply as soon as possible.

Data mistakes (a wrong contract, coach or pick) aren't security issues: open a **Data correction** issue instead.
